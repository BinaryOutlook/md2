# MD2 0.7.0

## New features

* Create and edit mind maps.
* Create blank diagrams in the app.
* Pin conversations for quick access.
* View project agent instructions in one place.
* Schedule actions by time, account reset, or card status.
* Create sequences to automatically run actions on a list of cards
* View and manage active schedules.
* Open cards and files in File Explorer.
* Switch statistics between charts and tables.
* Let actions request a version before running.

## Improvements and fixes

* Faster project opening, card creation, and action conversations.
* Improved diagram editing, legends, and touch controls.
* Clearer project settings and small-screen layouts.
* Fixed search results, conversation selection, and diagram editing issues.
